接下来进行第五课
复现功能
该软件是与一个.so文件在模拟器中进行获取的数据  接下来请复现so和软件在模拟器外的功能
1.解析so文件 复现so文件/像当前软件调用so文件都可以
2.复现当前软件的调用地址
如当前软件读取的按键链接.ini中的地址  但是按键链接.ini中的地址来源于so 然后进行转换后 在从模拟器进程进行读取的
如果只是用按键链接.ini的地址读取数据 那么模拟器环境/单机游戏重启 则失效
所以应该找出根地址   模拟器中so读取数据的方式  和 模拟器进程读取的方式

地址完成重启也可继续读取 视为完成  如果不依赖原版文件视为加分项
可先依赖原文件进行读取 后续在自写原依赖文件so会进行加分
